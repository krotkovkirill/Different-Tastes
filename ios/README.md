# Different Tastes для iPhone: прототип компаньона и виджета

Это исходники, не готовый установочный файл. На текущем Mac есть только Command Line Tools: Xcode и iOS SDK не установлены, поэтому локальная сборка iOS недоступна. В GitHub Actions настроена сборка приложения и расширения для симулятора без подписи. На физическом iPhone проект ещё не проверен. Swift-файлы проверяются на синтаксис, общий сетевой код и формат ответа отдельно проверяются на macOS.

Живой виджет iOS требует установленного приложения с расширением WidgetKit. Один сайт или PWA не создаёт такой виджет. Пользователям не требуется Scriptable или другое стороннее приложение: нужен только Different Tastes, когда появится подписанная сборка.

## Что подготовлено

- Приложение-компаньон: подключение кодом из профиля сайта, просмотр последней публикации и кнопка открытия сайта.
- Маленький и средний виджеты: фотография, автор, рейтинг и необязательный комментарий.
- Нажатие на подключённый виджет передаёт `differenttastes://feed` приложению, которое открывает HTTPS-сайт в браузере. На сайте используется обычная браузерная сессия; при необходимости пользователь входит.
- Отдельный доступ только на чтение последней публикации. Пароль в iOS-приложение не вводится.
- Общий Keychain для кода подключения, App Group для приватного кеша; кеш принадлежит конкретному коду. Известный отзыв/истечение кода очищает сохранённую публикацию. При временном отсутствии сети допускается кеш до суток с соответствующей подписью.
- Плановый запрос обновления через 20 минут. Это просьба к WidgetKit, а не обещание: фактическое время выбирает iOS. Мгновенное обновление после каждого поста и push не реализованы.

## Сборка на своём iPhone

1. Установить полный Xcode на Mac и открыть `DifferentTastes/DifferentTastes.xcodeproj`.
2. Выбрать схему `DifferentTastes` и свой iPhone (iOS 17+).
3. В Signing & Capabilities выбрать свою команду для обоих targets: `DifferentTastes` и `LatestTasteWidget`. Понадобится профиль подписи с поддержкой общего App Group и Keychain Sharing.
4. Проверить одинаковую App Group `group.com.krotkovkirill.DifferentTastes` и общий Keychain group `$(AppIdentifierPrefix)com.krotkovkirill.DifferentTastes.shared` в двух entitlements. Если меняются идентификаторы, согласованно заменить их в настройках проекта, обоих plist, entitlements и `Shared/WidgetConnection.swift`.
5. Запустить Run. Подпись, разрешение установки и доверие устройству выполняются владельцем Apple ID. Проект ещё нужно проверить в Xcode; тестовый iOS-архив/IPA не создавался.
6. На HTTPS-сайте открыть профиль → «Виджет iPhone» → «Создать код». В приложении вставить код и нажать «Подключить виджет».
7. Добавить Different Tastes из галереи виджетов iPhone. Проверить фото, рейтинг, пустой и непустой отзыв, нажатие, смену аккаунта/кода, отсутствие сети и отзыв доступа.

Для распространения другим людям потребуется подписанная iOS-сборка подходящим способом (например, TestFlight или App Store). До этого сайт остаётся полностью рабочим и отдельной установки не требует. Перед публикацией iOS-приложения также нужны иконка приложения, проверка на устройстве и оформление распространения.

## Файлы

- `App/DifferentTastesApp.swift` — настройка подключения и открытие сайта.
- `Widget/LatestTasteWidget.swift` — TimelineProvider и два размера виджета.
- `Shared/WidgetConnection.swift` — формат API, запрос с кодом, общий Keychain и кеш.
- `DifferentTastes.xcodeproj` — два targets и общая схема. Сторонний генератор проекта не нужен.

Сервер по умолчанию: `https://152.234.209.214/`. При смене домена обновить `TastesConfiguration.siteURL` и серверную переменную `DT_PUBLIC_URL`. Код подключения не добавлять в репозиторий, URL или скриншоты.

Документация Apple: [создание расширения](https://developer.apple.com/documentation/widgetkit/creating-a-widget-extension), [обновление виджета](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date), [переходы из виджета](https://developer.apple.com/documentation/widgetkit/linking-to-specific-app-scenes-from-your-widget-or-live-activity).
